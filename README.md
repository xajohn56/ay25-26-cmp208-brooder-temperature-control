Technical Project Title: Temperature Control System for Brooder
Problem Statement:
Students and lecturers at SALCC face challenges maintaining a constant brooding temperature, inconsistent temperature can affect chick health, disrupt scheduled laboratory activities, and limits the effectiveness of teaching and assessment within the college’s agricultural programme. 
Project Overview:
This project aims to design and develop an automated temperature control system for a poultry brooder to ensure consistent and optimal conditions for chick growth. In poultry rearing, maintaining a stable temperature is critical, especially during the early stages of a chick’s life. Fluctuations can lead to stress, poor growth, or even death. The proposed aims to system monitors and adjust the temperature automatically. By implementing this system, poultry farmers can improve efficiency, reduce human error, and minimize energy waste. The project aligns with sustainable agricultural practices by ensuring better resource management and promoting animal welfare.
Project Audience:
Agricultural  lecturers and students  at SALCC
Project Format:
This project would be done as a prototype as well as an application.
Project Scope:
Research temperature and other variable requirements for brooding in St. Lucia.
Research existing methods of designing the prototype of  the controlled-brooder system.
Design a temperature-controlled brooder system using sensors and microcontroller technology.
Build the prototype with components such as temperature sensors, heating element, and a cooling fan.
Develop a control algorithm that automatically maintains the desired temperature range by switching heating or cooling elements on/off.
Implement a display interface showing real-time temperature readings and system status.
Test the system under simulated brooding conditions to evaluate accuracy and reliability.
Optimize power consumption and sensor placement for consistent temperature regulation.
